# VoiceChat

Простой веб-чат «в духе Discord»:
- 💬 Текстовый чат с историей сообщений (хранится в SQLite, переживает перезапуск сервера)
- 🎤 Голосовой чат (WebRTC, mesh-топология)
- 🖥️ Демонстрация экрана
- 👥 Список онлайн-пользователей и участников голосового канала

## Стек

- Backend: Node.js, Express, Socket.io, better-sqlite3
- Frontend: чистый HTML/CSS/JavaScript (без сборщиков, ничего компилировать не нужно)

## Запуск локально

```bash
npm install
npm start
```

Открыть в браузере: http://localhost:3000

Чтобы протестировать голосовой чат — откройте два разных браузера (или одну обычную вкладку + одну в режиме инкогнито), войдите под разными именами.

## ⚠️ Важно про хостинг

Это **не статический сайт** — на сервере крутится Node.js-процесс (Express + Socket.io + база данных). Поэтому:

- **GitHub / GitHub Pages** — подходит только чтобы хранить код. Сам сайт GitHub Pages не запустит (там нет Node.js).
- Нужен хостинг, который умеет запускать Node.js-приложения и держать постоянное соединение (WebSocket). Бесплатные варианты:
  - **Render.com** (проще всего, есть бесплатный план)
  - **Railway.app**
  - **Fly.io**
  - Свой VPS (например, за ~150-300 руб/мес)

### Деплой на Render.com (пошагово)

1. Залейте этот код в свой репозиторий на GitHub.
2. Зайдите на [render.com](https://render.com), зарегистрируйтесь через GitHub.
3. New → Web Service → выберите свой репозиторий.
4. Настройки:
   - **Build Command:** `npm install`
   - **Start Command:** `npm start`
   - **Instance Type:** Free
5. Нажмите Create Web Service — через пару минут сайт будет доступен по ссылке вида `https://ваш-проект.onrender.com`.

> На бесплатном плане Render «засыпает» после ~15 минут без запросов и просыпается ~30-50 секунд при заходе — это нормально для бесплатного тарифа.

### Про базу данных на бесплатных хостингах

`chat.db` (файл SQLite) хранится на диске сервера. На некоторых бесплатных платформах (в т.ч. Render Free) диск **не постоянный** — при передеплое/перезапуске история может очиститься. Для настоящего долгосрочного хранения на бесплатном тарифе:
- либо используйте платный план с постоянным диском (Render Persistent Disk),
- либо замените SQLite на бесплатную облачную БД (например, Postgres на Supabase/Neon) — если понадобится, могу переписать хранение под это.

## ⚠️ Важно про голосовой чат (WebRTC) на разных сетях

Приложение использует публичные STUN-серверы Google, которых достаточно в большинстве случаев (домашний интернет, мобильный интернет). Но если один из собеседников сидит за корпоративным/строгим NAT или файрволом, соединение напрямую может не установиться — тогда понадобится **TURN-сервер** (он «пробрасывает» трафик через промежуточный сервер).

Бесплатные варианты TURN:
- [metered.ca/tools/openrelay](https://www.metered.ca/tools/openrelay/) — бесплатный публичный TURN, можно сразу подставить в `public/client.js` в массив `ICE_SERVERS`.
- Свой TURN-сервер (coturn) на VPS — надёжнее, но требует настройки.

Пример добавления TURN в `client.js`:
```js
const ICE_SERVERS = [
  { urls: 'stun:stun.l.google.com:19302' },
  {
    urls: 'turn:global.relay.metered.ca:80',
    username: 'ваш_логин',
    credential: 'ваш_пароль',
  },
];
```

## Ограничения текущей версии (и как их снять)

- **Один общий канал** («general») — легко расширить до нескольких текстовых/голосовых каналов, если понадобится.
- **Mesh-топология голоса** — каждый участник соединяется напрямую с каждым. Отлично работает для 2-8 человек. Для больших конференций (10+) нужен медиа-сервер (SFU, например `mediasoup` или `LiveKit`) — дайте знать, если нужно будет масштабировать.
- **Без регистрации/паролей** — вход просто по имени. Если нужна авторизация (логин/пароль, привязка к аккаунту) — тоже можно добавить.
- **Нет загрузки файлов/картинок в чат** — если нужно, добавляется отдельным модулем.
